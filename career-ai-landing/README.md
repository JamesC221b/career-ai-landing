# Career AI Landing Page

This is a simple static landing page for the Career AI project. It helps users find new career paths using AI-driven recommendations.

## How to Deploy on GitHub Pages

1. Clone this repository or upload the files to GitHub.

2. Go to **Settings > Pages** in your repository.

3. Set the branch to `main` (or `docs` if needed).

4. The site will be available at `https://yourusername.github.io/career-ai-landing/`.

Enjoy! 🚀
